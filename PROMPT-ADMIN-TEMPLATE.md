EVALÚA EL CÓDIGO BASÁNDOTE EN LOS SIGUIENTES PILARES "TODO-INCLUÍDO":

1. ESTRUCTURA Y LAYOUT (Layout & Grid):

- Uso correcto de sistemas de grid (CSS Grid/Flexbox).
- Jerarquía visual, espaciado (whitespace/padding/margin) y respiración entre elementos.
- Responsividad y adaptabilidad a diferentes viewports.

2. PALETA DE COLORES Y TEMAS (Colors & Theming):

- Consistencia en el uso de variables CSS/SCSS.
- Contraste y accesibilidad (WCAG).
- Uso de colores semánticos (success, warning, danger, info) y neutros.
- Preparación para Modo Oscuro/Claro (Dark/Light mode).
- Evitar colores "crudos" o saturados que cansen la vista en un ERP.

3. TIPOGRAFÍA (Typography):

- Jerarquía clara (H1 a H6, body, captions).
- Legibilidad, interlineado y pesos de fuente (font-weights).
- Uso de fuentes sans-serif modernas y profesionales.

4. NAVEGACIÓN Y MENÚS (Sidebar, Navbar, Menus):

- Sidebar: Estructura colapsable, agrupación lógica de módulos, estados hover/active/focus bien definidos.
- Header/Navbar: Breadcrumbs, perfil de usuario, notificaciones, búsqueda global.
- Menús desplegables (Dropdowns): Animaciones suaves, jerarquía visual clara.

5. COMPONENTES UI (Cards, Tables, Forms, Buttons):

- Tablas de datos (Data Tables): Filtros, paginación, estados de carga (skeletons), acciones por fila.
- Formularios: Inputs con labels flotantes o claros, validaciones visuales, agrupación lógica.
- Botones: Variantes (primary, secondary, ghost, danger), tamaños, estados (disabled, loading).
- Cards: Sombras sutiles, bordes, hover effects, uso de iconos de apoyo.

6. ICONOGRAFÍA Y GRÁFICOS (Icons & Data Viz):

- Uso de una librería de iconos consistente (ej. Heroicons, Material Icons, FontAwesome).
- Alineación perfecta de iconos con el texto.
- Espaciado en dashboards de gráficos (Charts).

7. BEST PRACTICES DE ANGULAR EN EL HTML:

- Uso correcto de directivas estructurales (*ngIf, *ngFor, @if, @for).
- Limpieza del template (evitar lógica compleja en el HTML, usar pipes o getters).
- Encapsulamiento y reutilización de componentes.
