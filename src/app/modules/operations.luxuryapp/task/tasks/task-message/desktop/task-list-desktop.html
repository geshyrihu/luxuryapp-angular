Como interactuar con las tareas

Reordenar tareas

Arrastra el icono ☰ de la columna izquierda hacia arriba o abajo para cambiar el orden. Si la tarea tiene subtareas, estas se mueven automaticamente con ella.

Asignar predecesora

Arrastra el icono 🔗 de una tarea y sueltalo sobre otra para marcarla como predecesora. La tarea arrastrada no puede iniciar hasta que la predecesora este completa.

Click en → FOLIO para quitar la dependencia.

Tareas padre e hijos

Las tareas con el icono tienen subtareas. Las tareas con son hijas de otra. Al crear o editar una tarea puedes asignarle una tarea padre.
