# Auditoría de nombrado — shared/ui

**Generado:** 2026-07-10 · Rama: `fix/ds-audit-phase1`
**Regla evaluada:** nombre físico del archivo == kebab-case(export class) == selector (para directivas de atributo se acepta `[camelCase]`).

## Resumen

- 592 archivos `.ts` (sin specs) · 471 clases decoradas (`@Component`/`@Directive`/`@Pipe`) · 121 sin decorador (interfaces, servicios, tokens).
- **Solo 30 de 471 cumplen la regla completa.**
- 342 archivos cuyo nombre físico NO corresponde al kebab de la clase.
- 263 clases cuyo selector NO corresponde al kebab de la clase.

## Casos especiales (más allá del prefijo)

- `adaptive/tap-to-top/tap-to-top.ts` → clase `LxScrollTop` (ni el nombre base coincide).
- `web/tap-to-top/tap-to-top.ts` → clase `ScrollTop`, selector `app-scroll-top`.
- `mobile/checkbox`, `mobile/divider`, `mobile/fieldset`, `mobile/file-upload`, `mobile/panel` → clases `Ili*` (rompen el patrón `Mobile*` de su carpeta).
- `mobile/tab-bar` → clase `AppTabBar` dentro de la carpeta mobile.
- `web/header-customer/haeder-customer.ts` → typo en el nombre del archivo («haeder»).
- `inputs/web/custom-input-upload-pdf-signal.ts` → clase `SubirPdf`, selector `app-subir-pdf` (sin relación con el archivo).
- `inputs/web/custom-input-autocomplete-multiple-signal.ts` → clase `CustomInputAutoMultiple` (abreviación inconsistente).
- `inputs/web/custom-input-select-prefix-signal.ts` → selector `web-custom-input-select-signal-prefix` (orden de palabras invertido).
- `iconfield`/`inputicon` (en adaptive, web y mobile) → clase `*IconField`/`*InputIcon` vs archivo/selector `iconfield`/`inputicon` (sin guion interno).
- `web/customer-360` → clase `AppCustomer360` vs selector `app-customer-360` (el kebab de la clase da `app-customer360`).
- Sufijo `Component`/`.component.ts` residual: `shared/action-icons-group`, `image-analysis-dialog`, `web/whats-new`.
- Directivas de atributo (`[lxTooltip]`, `[appFocusTrap]`, `[iliStyleClass]`…): el selector camelCase es correcto por convención Angular; solo el archivo carece de prefijo.
